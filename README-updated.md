# Gal-Gun2-Grabs-Only-Mod
The grab attacks are no doubt the best ones. It's just a shame that not all girls do it. Well, with this mod, now they do! All melee attacks are now grab attacks instead!

To use this mod, you will need to add UE4SS to your game's directory. The latest version should do. Link to that will be provided here along with how to add it: https://github.com/UE4SS-RE/RE-UE4SS

After installing UE4SS, you'll want to extract the mod files to C:\Program Files (x86)\Steam\steamapps\common\GalGun 2\GalGun2\Binaries\Win64 , Or wherever your Gal Gun 2 game directory is. The mod will then be added to UE4SS. 

Then after running the game, the mod will be enabled.
