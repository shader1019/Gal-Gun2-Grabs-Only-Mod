# Gal-Gun2-Grabs-Only-Mod
The grab attacks are no doubt the best ones. It's just a shame that not all girls do it. Well, with this mod, now they do! All melee attacks are now grab attacks instead!

To use this mod, you will need to add UE4SS to your game's directory. The latest version should do. Link to that will be provided here: https://github.com/UE4SS-RE/RE-UE4SS

After installing UE4SS, you'll want to extract the files to C:\Program Files (x86)\Steam\steamapps\common\GalGun 2\GalGun2\Binaries.

Full Disclosure: AI was used to make this, along with a lot of trial and error. I wanted to make this for myself, but thought some people might want a mod like this too. If you hate that AI helped make this, safely ignore this mod. But if you don't care and want the girls to grab you all the time, I hope you enjoy the mod. :)
